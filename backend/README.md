# Kavach — Backend

FastAPI server + YOLOv8 detection engine for the border surveillance dashboard.

## Layout

```
backend/
├── run.py              # entry point: build sync → server thread → detection loop
├── app/                # all Python source (the importable package)
│   ├── config.py       # every path + tunable lives here — nothing else hardcodes paths
│   ├── server.py       # FastAPI app: REST commands, /ws stream, static + mobile routes
│   └── detect.py       # YOLO detection loop, zones, tripwires, threat scoring
├── web/                # things served to a browser
│   ├── mobile.html     # standalone mobile page (/mobile)
│   └── static/         # React build — generated by run.py, not checked in
├── models/             # YOLO weights (.pt) — large, not checked in
├── data/videos/        # sample footage — large, not checked in
├── logs/               # runtime alert logs, written by detect.py
│   └── archive/        # logs kept from earlier test runs
└── tests/              # layout + import smoke tests
```

## Run

```bash
pip install -r ../requirements.txt     # pinned deps live at the project root
cd ../frontend && npm run build        # produces frontend/build/
cd ../backend && python run.py
```

Opens `http://localhost:8000` (desktop) and prints the LAN URL for `/mobile`.

## Test

```bash
python -m unittest discover -s tests -t .
```

## Conventions

- **Paths belong in `app/config.py`.** If you need a file location, import it from
  there. Moving a folder should be a one-line change.
- **`app/` holds source only.** Anything written at runtime goes to `logs/`;
  anything large and fetchable (weights, footage) goes to `models/` or `data/`
  and stays out of git.
